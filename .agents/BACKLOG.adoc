== 🟡 EPIC RUN-I18N-ARTIFACT — Le rapport de convergence mesure l'artefact (CADRÉ S-077, revue i18n S-263)

*Source* : revue externe `foundry/public/bakery-gradle/bakery-plugin/.agents/i18n_review.adoc`
(S-263) ; gate d'artefact cheroliv.com S-077 (`ArtifactIntegrity`,
`reportArtifactIntegrity`).

*Constat* : `reportConvergence` compte des **blocs du store** (`PENDING`/`TRANSLATED`)
et peut annoncer « 0 PENDING / 0 cassé » alors que l'artefact publié contient des
refus LLM, des macros perdues ou des duplications. C'est le faux vert que la revue
a identifié : l'orchestration N3 doit exposer la mesure de l'artefact, pas seulement
l'état du travail.

*Boundary* : runner est un **consommateur terminal** — il n'implémente aucune règle
métier. Il orchestre les rapports produits par les boroughs (site, document,
bakery, plantuml) et refuse un déploiement non prouvé.

*DAG* : `cheroliv.com (ArtifactIntegrityContract)` + `MEMPHIS/CB/DOC/BKY/PLT`
→ `runner (RUN-I18N-ARTIFACT)`. Aucun import N3 → N0/N1/N2.
